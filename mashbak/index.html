Official SMS Service Information

Yeshiva Chill Mashbak SMS Assistant

Mashbak is an SMS-based assistant service operated by Yeshiva Chill. The service is available only to authorized users and responds to user-initiated text messages. It is not used for marketing campaigns, bulk promotional messaging, or unsolicited outbound texts.

Opt-In Privacy Terms Contact Support
Service type: Conversational SMS assistant for authorized users. Messages are user-initiated and transactional/conversational in nature.

Opt-In

Users request access by texting the opt-in keyword:

join@bucherim

When this keyword is received, the request is reviewed and, if approved, the user's phone number is added to the list of authorized users for this service.

Consent: By texting join@bucherim, you consent to receive SMS messages from Yeshiva Chill Mashbak. Message frequency varies. Message and data rates may apply. Reply STOP to opt out. Reply HELP for help.

Authorized Use Only

This service is intended only for users authorized by Yeshiva Chill. Unauthorized numbers are not enrolled for ongoing access and may be denied service.

This service does not send unsolicited messages. All messages are initiated by the user.

Opt-Out and Help

Users may stop messages at any time by replying:

STOP

Replying STOP removes the user from assistant responses unless they opt in again later.

Users may request assistance by replying:

HELP

Message Frequency

Message frequency varies based on how often an authorized user texts the assistant. The service is conversational and reply-based, not scheduled marketing.

  • No bulk promotional campaigns
  • No purchased lead lists
  • No auto-enrollment without user action

Privacy Policy

Yeshiva Chill may collect a user's phone number, message content, and basic delivery data only as needed to operate the Mashbak SMS assistant.

  • Information is not shared for third-party marketing purposes.
  • Users may opt out at any time by replying STOP.
